# Design

## Context

动机见 `proposal.md` — Why。塑造形态的实测事实：

| 事实 | 值 |
|---|---|
| 入口规模 | 901 行 · 22 函数 · 1 类（`Scope` 54 行）· 16 声明 · 39 公共名 |
| 最大函数 | `_ledger_roster_problems` 69 行 |
| **顶层环** | `_battery` ← 入口：10 常量 + `Scope` + `RULES` + `violations`；入口 ← `_battery`：顶层 import |
| 环为何"能用" | 只因定义顺序恰好让回环取到已初始化的名字——阶段 1 记录里"刻意避开包化"的理由正是它 |
| 电池清单 | 43 条控制（31 负例 + 12 绿色），pin 被测试钉死 |

## Goals / Non-Goals

**Goals:** 入口变薄且文件名不变 · 环被消除（双方单向依赖包）· 命令行契约与 43 条控制逐字不变 ·
39 公共名零缺失 · 体积表按实测重测。

**Non-Goals:** 不改任何规则语义 · 不拆 `_battery.py`（第二把）· 不重构 `Scope` · 不动 CAS。

## Decisions

### D-1｜拆出包，而不是把电池合并进入口

- **选**：`doc_hygiene_check/` 包承载声明、`Scope`、规则与 CLI；入口只做门面与 CLI 调用。
- **为什么**：环的根源是"两个文件互相需要对方的顶层名字"。把**共同需要的那部分**下沉到包，
  电池与入口都向上依赖包 ⇒ 环自然消失，而不是靠 import 顺序的巧合维持。
- **代价**：一个 6 模块的包。
- **换来**：依赖方向可陈述、可检查；入口回到薄层。

### D-2｜`constants.py` 与 `scope.py` 先行（本次实现的第一步）

- **选**：第一批下沉的是电池实际需要的 12 个名字（10 个声明常量 + `Scope` + `RULES`/`violations`
  的宿主）。
- **为什么**：这是**环的断点**。先断开它，后续搬规则时每一步都仍在"无环"状态下验证。
- **代价**：分两步搬，中间态多一次提交。
- **换来**：每步都能以"治理套件 + 七 checker 全绿"为边界提交（可回滚）。

### D-3｜规则的再导出用显式块 + `__getattr__` 兜底

- **选**：入口显式再导出全部 39 个公共名，并加 `__getattr__` 兜底转发到包。
- **为什么**：阶段 4 的教训——双层再导出会被 linter 反复删除（需 `__all__` + 块级豁免）；
  而 `__getattr__` 兜底能让"我漏列了一个名字"表现为**可用**而不是 ImportError。
- **代价**：两处机制并存。
- **换来**：公共面零缺失有了双保险，且缺失会被 `--self-test` 与套件立刻发现。

### D-4｜电池改从包导入（本把只改导入来源）

- **选**：`_battery.py` 的 12 个名字改为从 `doc_hygiene_check` 取；其自身拆分留待第二把——**追记（2026-10-18）：第二把即 change `split-control-battery`（2026-10-17），已落地**。
- **为什么**：环必须在**两侧之一**断开才真正消失；先改电池的导入来源是最小改动。
- **代价**：电池仍是一个 724 行的单文件（下一步处理）。
- **换来**：环消失；且电池的拆分可以在"无环"前提下安全进行。

### D-5｜体积表按实测重测（入口降、新模块入表）

- **选**：入口上限下调到实测值；6 个新模块各按其实测值入表。
- **为什么**：表的规则是"上限 = 实测值"；入口变小后若保留 901，它就又能悄悄长回去。
- **换来**：拆分永久锁定，且新模块从一开始就在闸下。

## Risks / Trade-offs

- [搬错边界导致环复发或名字缺失] → 两批走（声明/Scope 先，规则后），每批后跑治理套件 + 七 checker；
  入口加 `__getattr__` 兜底，缺名字不会静默。
- [`_battery` 的导入来源改了却漏了某个控制] → 43 条控制由 `failing_controls()` 直接判定；若某控制
  取不到名字，它会立刻失败。
- [`--self-test` 的输出或退出码变了] → tasks 里对 `--self-test` 做**前后逐字对照**（stdout 与退出码）。
- [公共名漏列] → 39 个名字逐一可达性检查（脚本遍历入口 `dir()` 与包对比）。
- [体积表漏更新某模块] → 闸与三条预算测试会报；按实测值补。

## Migration Plan

1. 建包骨架 + `constants.py` + `scope.py`；`_battery` 改导入来源；门禁绿（**断环**）。
2. 搬规则与 `RULES`/`violations` 到 `rules.py` / `ledger.py`；入口再导出；门禁绿。
3. 搬 `main`/`--self-test` 到 `cli.py`；入口变薄 + `__getattr__`；`--self-test` 前后对照；门禁绿。
4. 体积表重测 + `required-paths.toml` 登记 + 39 公共名核对 + 收口。

**回滚**：撤销该步 diff（包目录删除、入口恢复）。
